NeuralFrame Case Events

The table onc_neuralframe_case_events contains details about the events recorded for each patient, including radiation, chemotherapy courses, treatments, and any relevant clinical observations.

Internal Stanford tracking ID for NeuralFrame.

NeuralFrame patient-set identifier used to group related patient records.

Unique identifier for each NeuralFrame case entity.

nfpatienteventid

Unique identifier for each NeuralFrame patient event record.
