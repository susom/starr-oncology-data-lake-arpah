Neural Frame Event Table

The Neural Frame Event table captures detailed clinical events and treatment information for cancer patients, including chemotherapy, radiation, surgery, clinical protocols, and various treatment outcomes. This comprehensive event-level data enables in-depth analysis of treatment patterns, clinical course, and patient outcomes.

ARIA (Radiation Oncology Information System) provides per-phase radiation treatment logistics that are not available from general NF abstracting. These include target volumes, lymph node involvement, daily/total dosing, fraction counts, and treatment end dates.
